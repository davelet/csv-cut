# CSV Cutter

CSV Cutter 是一个简单易用的CSV文件处理工具，它提供了图形用户界面，让你可以方便地选择和保留CSV文件中的特定列。

## 功能特点

- 友好的图形用户界面
- 支持选择本地CSV文件
- 显示文件基本信息（大小、行数）
- 可视化选择要保留的列
- 导出处理后的CSV文件

## 技术栈

- 使用Rust语言开发
- 基于iced框架构建GUI
- 使用csv库处理CSV文件

## 安装

确保你的系统已安装Rust开发环境，然后执行：

```bash
# 克隆项目
git clone [项目地址]

# 进入项目目录
cd csv-cut

# 编译运行
cargo run
```

## 打包（Mac）
```bash
cargo bundle --release
```

## 使用方法

1. 点击"选择CSV文件"按钮，选择要处理的CSV文件
2. 程序会显示文件的基本信息，包括文件大小和总行数
3. 在列表中勾选你想要保留的列
4. 点击"保存"按钮导出处理后的文件
